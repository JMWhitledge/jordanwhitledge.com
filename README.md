# jordanwhitledge.com

Personal-brand site for **Jordan M. Whitledge**: CFA® charterholder, CFP® professional, MBA, Adjunct Professor of Economics. Advisor, educator, speaker, and author of *The Whitledge Brief*.

> *"Common Sense Finance. Uncommon Wealth."*

## How it works

Plain static HTML and one shared stylesheet, hosted on **Vercel**. Every push to `main` deploys to https://www.jordanwhitledge.com. Branches get a Vercel preview URL.

- Pages: `index.html`, `about.html`, `the-brief.html`, `speaking.html`, `teaching.html`, `resources.html`, `contact.html`, `subscribe.html`, plus `privacy.html`, `disclaimers.html`, `404.html`
- Brief essays: `the-brief/<slug>.html`, published by copying `the-brief/_TEMPLATE.html`
- Newsletter: Kit · Contact form: Formspree · Analytics: Google Analytics 4 + Vercel Web Analytics

Brand specs, compliance rules, integrations, and open items are in [`CLAUDE.md`](CLAUDE.md). The `blocks/` folder and `v2-brief.md` are kept for reference from the earlier Squarespace plan and are not part of the live site.
